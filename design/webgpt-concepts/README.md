## 프로젝트 설명

Cabin Story는 Pleos Connect 차량 중심의 가족 여행 동행 서비스다. 가족은 하나의 여행 일정을 공유하고, 운전자는 짧은 한국어 음성 도슨트를, 동승자는 개인 기기에서 일반 설명 또는 여우 루루가 안내하는 어린이 그림책을 경험한다. 운전자가 가족의 조회·제안·편집 권한을 부여한다. 공유 일정 변경과 실제 내비 목적지 적용은 다른 단계이며, 운전자가 정차 중 최종 확인한다.

현재 MVP는 경주의 첨성대·대릉원·동궁과 월지, 국립경주박물관 추가 후보를 내장한다. 네트워크는 가족 기기의 로컬 공유에 사용하고 여행 콘텐츠는 오프라인이다. 실제 내비 도착·실차 안전성이 검증됐다고 주장하지 않는다.

## 공통 디자인 방향 — GPT

Material 3의 정보 위계·컴포넌트·선택/비활성 상태를 토대로 따뜻하고 단정한 여행 서비스로 구성한다. 숲빛 primary #216451, ivory surface #F6F5EF, dark ink #183E35, sage container #E7EEE6, muted terracotta 포인트. 8pt 간격, 24pt 카드 여백, 충분한 대비, 큰 한국어 제목. 차량은 64dp 이상 주요 조작, 모바일 48px 이상 터치 영역. 여우 루루는 작은 주황색 몸·크림색 얼굴·숲빛 목도리의 일관된 창작 캐릭터다. 삽화는 부드러운 종이 질감의 경주 풍경으로, 운전자 화면에서는 주행 중 큰 삽화·긴 본문을 숨긴다.

이미지에는 한 화면만 담는다. 다중 화면 콜라주·전후 비교·추가 변형은 요청하지 않는다. 차량 16:9 가로, 모바일 9:19.5 세로. 한국어 텍스트는 짧게, 핵심 제목·버튼만 명확하게. 차량·앱 제조사 로고는 모방하지 않고 Cabin Story 자체 브랜드를 사용한다.

## 수집과 후속 작업

WebGPT는 사용자가 이번 작업에 명시적으로 선택한 Edge의 Chat 표면에서 사용한다. 각 이미지의 실제 생성·다운로드 여부와 검토 결과를 기록한다. 생성 이미지는 구현·SDK 검증 증거가 아니며, 그림 속 잘못된 문구·상태는 실제 코드에 그대로 옮기지 않는다. 수집 후 GPT가 정보 구조·레이아웃·상태 규칙을 검토하고, 제품 코드 개선은 DeepSeek 유닛 구현 → GPT 인수로 진행한다.
