# GPT 유닛 인수 기록

추가 모델 지시 이전의 초기 제품 코드는 GPT가 작성했다. 이후 제품 변경은 아래와 같이 DeepSeek가 실제 편집했다. GPT는 과제·수용 기준·테스트를 작성하고 변경 내용을 검토했다. 실행 로그와 각 모델의 결과 원문은 로컬 evidence/에 보관하며 소스 ZIP에는 포함하지 않는다.

| 순서 | 유닛 | 실제 구현 모델 / 경로 | GPT 검증 |
|---|---|---|---|
| 1 | U1 통신 수명 | opencode-go/deepseek-v4.1-flash, 로컬 모델 경로 | join/close 동일 잠금, 소켓 쓰기는 잠금 밖, 종료 후 토큰 무효·중복 close, HTTP 4개 통과 |
| 2 | U2 여행 상태 | 동일 | 성공한 add/accept 이후 중복 제안 모두 제거. 실패 시 제안 유지 경계 확인. 도메인 8개·전체 12개 통과 |
| 3 | U6 패키징 | 동일 | .NET 정적 extension 호출 오류를 같은 모델에 재수정 요청. 생성 성공, 필수 경로 포함·키/캐시 제외 검사 통과 |
| 4 | U4 큰 글씨 표현 | 동일 | 유일한 제품 변경은 rail 폭 조건. release 빌드·실제 설치 후 fontScale1.5에서 한글 메뉴와 오디오 조작 확인 |

U3 오디오/차량 SDK와 U5 동승자 표현은 기존 구현을 유지하며 GPT가 실동작·화면을 검토했다. 작성자를 바꾸기 위한 전면 재작성은 하지 않았다. 일반·키즈 전환, 장면 1~3, 검색, 권한·공유 편집, 연결 끊김 및 360/800px 화면을 확인했다.

범위 외 작업: 실차/실물 휴대폰, 전국 콘텐츠, 서버 음성, 일괄 경유지 경로, 접수서 서명·메일 제출. 인수는 위 MVP 동작과 로컬 산출물에 한정한다.
