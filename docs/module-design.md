# 구현 유닛과 모델 책임

2026-11-14 추가 지시부터 적용: **GPT는 디자인 규칙·모듈 설계·QA 계획/테스트/리뷰를 소유하고, 실제 제품 코드 구현과 수정은 DeepSeek로 실행한다.** 이전에 작성한 제품 코드는 GPT가 작성했으며 이를 DeepSeek 작성 코드라고 표시하지 않는다. 동작하는 기존 코드를 작성자 변경만을 위해 전면 재작성하지 않는다.

## 공통 디자인 규칙

Material supporting pane, 8dp 간격, 차량 64dp 조작 영역, 모바일 48px 이상, 표제/본문/보조 정보 위계를 유지한다. 실제 정차 신호가 없으면 편집을 제한한다. 차량은 음성 중심, 개인 기기는 설명·그림책·탐색 중심이다. 넓은 그림책 화면에서도 장소와 캐릭터 전체가 보이게 한다. 색만으로 상태를 전달하지 않고 글과 disabled 상태를 함께 사용한다. 상세 규칙은 implementation-plan.md 참조.

## 유닛별 책임 / 외부 계약

| 유닛 | 소유 파일 | 책임과 경계 | GPT 인수 기준 |
|---|---|---|---|
| U1 가족 통신 | FamilyServer.java, TripStore의 세션 정리 API | HTTP 파싱·인증·초대·종료. 여행 변경은 TripStore만 호출. 종료 후 새 연결·옛 토큰 재사용 금지. | 잘못된 초대/무권한/교차 origin/오래된 버전/철회·종료 차단 |
| U2 여행 상태 | TripStore.java, places.json | ID·버전·권한·제안·방문 상태·저장. 외부 서비스 호출 없음. 실패 시 변경 롤백. | 원자성·복구·동시 편집·최소 한 곳·조회자 편집 금지 |
| U3 오디오·차량 | DocentPlayer.java, VehicleBridge.java | ON_DEVICE TTS·포커스, 실제 SDK·모의 입력 구분. SDK 수명과 UI 수명 종료 안전성. | 3문단 완료, pause/resume/stop, 실제 P와 위치 수신, 미검증 내비 성공 표시 금지 |
| U4 차량 표현 | MainActivity.java, AndroidManifest.xml, res/ | View 렌더·정차 제한·운전자 확인. 도메인 규칙 복제 금지. | 주행/미확인 제한, 실제 권한 경로, 데이터 저장 유지, 큰 글씨 조작 가능 |
| U5 동승자 표현 | phone.html, phone.css, phone.js, art/ | 같은 상태의 그림책/본문/일정. 권한 검사는 서버가 최종 수행. | 좁고 넓은 화면, 장면·모드 전환, 편집 공유, 끊김 표시, 이미지 잘림 방지 |
| U6 산출물 | Gradle, build.ps1, README·문서 | 실행 가능한 로컬 서명 release, 소스 패키지. 비밀·캐시 제외. | 빌드·lint·서명·release 실제 설치, 제출 상태 과장 금지 |

한 번에 한 유닛의 변경만 DeepSeek에 맡기고 GPT가 diff와 해당 검증 결과를 검토한 뒤 다음 유닛으로 이동한다. 모델 실행 로그에서 실제 provider/model을 확인한다. 선택한 모델을 쓸 수 없으면 다른 모델로 바꾸지 않고 사용자에게 알린다. GPT는 제품 코드를 직접 고치지 않고 다음 유닛에 수정 지시한다. QA 테스트 코드는 GPT가 작성·유지한다.
