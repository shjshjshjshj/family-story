# WebGPT 컨셉 검토와 UI/UX 개선 설계

> **대체됨 — 2026-11-14:** 사용자가 생성 컨셉을 제외하고 협동 경로 플래너·도슨트·계획/방문 기록을 서비스 중심으로 정정했다. 후속 기준은 `planner-rebaseline.md`다. 아래는 이전 작업 이력이다.

2026-11-14 · GPT 설계/QA, DeepSeek 제품 구현. WebGPT는 사용자가 선택한 Edge의 Chat에서 화면별 1장씩 순차 생성했다. 원본 9장은 `design/webgpt-concepts/`, 생성 프롬프트와 실제 채팅 URL은 같은 폴더의 manifest에 보관한다. 생성 채팅은 원본 검토 후 정리하고 Library 파일은 보존했다.

## 채택할 패턴

| 컨셉 | 적용할 패턴 | 실제 제품에서 바로잡을 점 |
|---|---|---|
| 01 차량 홈 | 짙은 숲빛 rail, 다음 장소의 위계, 우측 일정/가족 supporting pane | 가짜 가족·연결 인원·방문 진행률을 만들지 않는다 |
| 02 주행 오디오 | 짧은 장소 정보와 큰 재생·중단, 나머지 탐색 제한 | 초 단위 진행률·전체 시간을 발명하지 않는다. 문단 상태만 제공 |
| 03 차량 일정 | 순서 목록, 변경 상태, 운전자 확인과 내비 요청 분리 | 추가 탭·새 기능 없이 기존 4개 rail 유지 |
| 04 차량 가족 | 초대 안내와 기기 권한 관리 영역 분리, 3단계 안내 | 실제 초대 주소 유지. 가짜 QR·짧은 예시 코드를 실제로 쓰지 않는다. 역할은 개별 선택 |
| 05 모바일 참여 | 따뜻한 첫 인상, 명확한 두 필드와 CTA, Wi-Fi 안내 | 삽화 높이를 줄여 360px에서도 입력을 빨리 찾도록 한다. 같은 Wi-Fi는 필수이며 '더 빠름'으로 완화하지 않는다 |
| 06 모바일 일정 | 장소 썸네일, 방문 순서/상태, 이야기·일정·가족 3개 목적지 | 역할을 스스로 바꾸는 드롭다운 제외. 일정 확인 후 내비가 자동 반영된다는 문구 제외 |
| 07 일반 상세 | 장소명·설명·출처·공유 일정 복귀 | 휴대폰 음성 버튼·예상 재생 시간 제외. 기존 원고·공식 출처 유지 |
| 08 그림책 | 장소/제목 위계, 온전한 삽화, 이전·다음과 장면 수 | 장면 1에서 이전 비활성, 마지막에서 다음 비활성. 기존 일관된 루루 원본 삽화 4장 유지 |
| 09 모바일 가족 | 내 기기 강조, 역할별 할 수 있는 일, 가족 목록, 재연결 도움 | 서버가 준 구성원만 표시. '연결됨'은 통신 성공에 한정하고 다른 기기 온라인 여부를 추정하지 않는다 |

## 구현 전 확정 규칙

Material의 navigation rail/supporting pane 및 모바일 navigation bar를 기반으로 한다. 팔레트는 forest #216451, ivory #F6F5EF, ink #183E35, sage #E7EEE6. 기존 원본 삽화와 책 심볼을 공통 브랜드로 유지한다. 컨셉마다 달라진 로고·인물·여우를 복제하지 않는다. 본문은 시스템 한국어 글꼴, h1 28~32px, h2 22~24px, 본문 16~18px, 보조 13~14px. 8px 간격, 카드 20~24px 여백, 모서리 20~24px. 모바일 조작 48px 이상, 차량 주요 조작 64dp 이상. 색과 텍스트로 상태를 함께 표시하고 포커스를 유지한다.

모바일 360px에서는 단일 열, 좌우 여백 20px, 하단 navigation 3개를 균등 배치한다. 700px 이상은 기존 그림책의 삽화/원고 2열을 유지하고 가로 넘침 없이 기기 목록·일정을 읽는다. 200% 텍스트 확대에서도 카드·버튼이 내용 높이에 맞춰 늘어난다. 그림책은 contain으로 장소와 루루 전체를 표시한다. 큰 장식 이미지나 배경에 문구를 굽지 않는다.

모바일 연결 후 기본 화면은 기존 그림책을 유지한다. 이야기 안에서 어린이/성인 모드를 전환한다. 일정의 장소를 누르면 해당 이야기를 열고, '공유 일정으로 돌아가기'로 복귀한다. 가족 탭은 내 기기 이름/권한, 허용 범위 3행, 실제 참여 기기와 최근 변경, 재연결 도움을 제공한다. 가족 권한 변경은 차량에서만 한다. 연결 끊김에는 마지막 상태임을 명시하며 편집을 차단한다. session/인증/버전 충돌 로직은 유지한다.

차량은 기존 4개 rail과 행동을 유지한다. 숲빛 rail/선택 상태를 정돈하고, 실제 정차 판정을 제목 근처에서 읽을 수 있게 한다. 주행 또는 미확인 상태에서는 홈의 오디오와 짧은 안전 문구만 두고 큰 삽화·정차용 세부 작업을 막는다. 일정/가족 화면의 정보는 제목 → 요약 상태 → 목록 → 조작 → 보조 안내 순서로 구성한다. 디버그 상세는 진단 화면에 둔다. 데이터나 SDK 성공 판정은 바꾸지 않는다.

## 순차 유닛과 QA

1. U5: phone.html/css/js만 개선. 기존 API와 데이터 계약을 재사용. GPT가 실제 Edge에서 360/800px, 그림책 3장면, 성인 원고/출처, 탭/복귀, viewer/editor/proposer 권한 안내, 이름 안전 렌더링, 끊김/철회, 포커스/가로 넘침을 확인.
2. U4: MainActivity.java만 개선. GPT가 release 빌드·동일 서명 업데이트, 차량 홈/일정/가족/진단, 모의 주행 제한, TTS, 1.5 글씨 배치를 확인.
3. GPT: APK 서명/소스 ZIP 갱신, 변경 범위와 실제 확인 결과 기록. 기존 도메인/HTTP 12개 테스트는 해당 로직 변경이 없으면 이전 결과로 구분하고 새 실행이라고 주장하지 않는다.

실차·실물 휴대폰 LAN·내비 경로 탐색 완료·완전한 TalkBack 인적 검증은 이번 표현 변경만으로 검증됐다고 하지 않는다. 공모전의 Java/API28+/Gradle8+/Pleos SDK 및 release/소스/README 조건을 유지하며 실제 접수는 하지 않는다.
