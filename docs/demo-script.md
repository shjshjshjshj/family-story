# 3분 시연 대본

목적: 같은 여행을 차량에서는 음성으로, 동승자 기기에서는 그림책으로 경험하고, 운전자의 통제 아래 일정을 함께 바꾸는 모습을 보여준다. 실제 결과와 모의 입력을 구분한다.

## 준비

Pleos v2.1.0 Cold Boot, APK 실행, P단 수신 확인. PC에서 `adb forward tcp:8787 tcp:8787` 후 모바일 크기 브라우저를 연다. 인터넷 연결은 필요하지 않고 PC와 에뮬레이터의 로컬 통신만 필요하다. 동승자 기기 이름을 입력하고 운전자가 편집 권한을 부여한다. 위치 권한은 미리 허용하되 관측되지 않은 도착 이벤트를 성공 사례로 설명하지 않는다.

| 시간 | 보여줄 장면 | 말할 내용 / 증거 |
|---|---|---|
| 00:00~00:30 | 차량의 다음 장소·오늘의 일정, 휴대폰 여행 제목 | 하나의 여행, 같은 장소 ID와 일정. 샘플 경주 콘텐츠 내장. |
| 00:30~01:05 | 차량 `이야기 듣기`, 잠시 멈추기·이어듣기 | Pleos ON_DEVICE 한국어 실제 합성. 이어듣기는 중단 문단 처음부터. |
| 01:05~01:40 | 휴대폰 루루의 그림책 1~3장면, 어른의 이야기 전환 | 장소는 같고 표현이 다름. 차량 화면에서 긴 글을 읽지 않음. |
| 01:40~02:20 | 동승자 일정에서 박물관 추가 → 차량 4번째 방문지 표시 | 실제 로컬 HTTP 변경. 운전자 확인 대기. 내비가 바뀌었다고 말하지 않음. |
| 02:20~02:45 | 차량에서 변경 일정 확인, 가족 권한 철회 | 공유 플랜 확인과 실제 내비 목적지 요청 분리. 철회 기기의 접근 차단. |
| 02:45~03:00 | 에뮬레이터 `시연 모드 → 모의 주행` | ‘모의’ 표기를 보이며 삽화·편집 제한 확인. 실제 주행 신호 검증과 구분. |

실제 위치 기반 자동 안내를 시연하려면 Virtual Console/에뮬레이터의 위치를 첨성대 인근으로 설정하고 `연동 진단 → 접근 시 자동 안내`를 켠다. 화면에 FusedLocation 이벤트가 실제 기록된 경우에만 SDK 이벤트 성공으로 소개한다. 내비의 실제 경로 탐색이 검증되지 않았다면 요청 상태까지만 설명한다.

시연 뒤 ‘실제 SDK’ 모드로 돌린다. 초대 링크가 담긴 화면은 공개 영상에서 가리거나 시연 종료 뒤 앱을 닫아 링크를 만료시킨다.
